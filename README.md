# Thiranex Virtual Internship – Task 02

## Predictive Modeling Using Machine Learning

This project is completed as part of my **Virtual Internship at Thiranex**.

The objective of this task is to build machine learning models that can predict whether a customer will respond to a marketing campaign based on their demographic information, purchasing behavior, spending patterns, and previous campaign interactions.

## Project Objective

The main objective of this project is to apply supervised machine learning algorithms to a real-world dataset and evaluate their ability to predict customer responses.

The project focuses on:

- Preparing data for machine learning
- Selecting relevant features
- Creating useful features from existing data
- Splitting the dataset into training and testing sets
- Training multiple machine learning models
- Predicting customer responses
- Evaluating model performance
- Comparing different machine learning algorithms
- Visualizing model performance
- Identifying important features

---

## Dataset

The project uses a **Marketing Campaign dataset** containing information about customers, their demographics, purchasing behavior, product spending, website activity, and previous marketing campaign responses.

The dataset contains information such as:

- Customer ID
- Year of Birth
- Education
- Marital Status
- Income
- Number of Children
- Product Purchases
- Website Purchases
- Catalog Purchases
- Store Purchases
- Previous Campaign Responses
- Current Campaign Response
